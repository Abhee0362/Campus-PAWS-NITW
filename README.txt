Campus Paws NITW — Face-Safe Final

RUN LOCALLY
1. Extract this ZIP.
2. Open this folder in VS Code.
3. Keep index.html and the images folder together.
4. Run index.html with Live Server.

DEPLOY
Upload the entire contents of this folder (index.html plus images/) to your host. Do not upload only index.html.

PHOTOS
The website includes hero.jpg, dog1.jpg, dog2.jpg, dog3.jpg, upi-qr.jpeg and 20 selected images under images/dogs/. Photo cards use object-fit: contain so the full image is visible without cropping the dog's face.

PAYMENTS
This is a static frontend. It does not independently verify UPI payments or synchronise a public ledger. That requires a secure backend and payment provider integration.
